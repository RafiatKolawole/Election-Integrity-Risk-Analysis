# Election Integrity Risk Analysis (2019 vs 2023)

## Project Overview
This project analyzes election polling unit data and election observer incident reports to identify voting anomalies, assess electoral integrity, and predict high-risk Local Government Areas (LGAs) for future elections.

Using Power BI, the project combines data cleaning, transformation, modeling, and interactive visualizations to develop a Risk Score that highlights areas requiring closer election monitoring. The analysis compares election data from 2019 and 2023 to uncover trends, improvements, and emerging risk patterns.

## Objectives
- Merge polling unit data with election incident reports.
- Standardize LGA names for accurate data integration.
- Detect election anomalies such as over-voting, perfect turnout, zero turnout, and suspiciously low turnout.
- Calculate Risk Scores for each LGA.
- Compare election integrity trends between 2019 and 2023.
- Build an interactive Power BI dashboard for decision-making.
